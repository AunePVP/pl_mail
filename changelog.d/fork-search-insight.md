**A search shows what it is probably about before the list.** Searching for "Flug", "Zug", "Hotel"
or a word in an event's title shows the coming calendar entries it matches above the results, each
with the mail that belongs to it — the confirmation, the check-in, the security-lane slot — in one
line instead of eight. With "Summaries" switched on, the chat model then reads the first twenty
results and answers in a sentence or two, links the mail worth opening, and groups results that are
about the same trip or order. Both load after the list, which never waits for them. No schema
change.

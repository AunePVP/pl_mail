**Newsletters get an Unsubscribe button in the message header, always in the same spot.** It sits
beside the date and in the ⋮ menu, and points where the sender's List-Unsubscribe header says: a
web link opens the sender's unsubscribe page in a new tab, an address opens a draft to it. plMail
sends nothing by itself. Mail without the header shows no button, and neither does mail in spam or
the bin, where unsubscribing would mostly confirm to a spammer that the address is read. No schema
change.

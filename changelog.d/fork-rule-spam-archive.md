**A filter that marks mail as spam moves it into the spam folder on the server too.** It used to
label the mail Spam in plMail and archive it on the server, so phones and other mail programs found
it in the archive and the server's spam filter never saw it. A filter that archives mail now also
files it under Archive; before, the mail left the inbox and was in no list at all. Mail filed the
old way stays where it is. No schema change.
